# SIH26102 — Frontend Requirements

## Pages

### Overview Dashboard
Show:
- total works
- recommended amount
- expenditure
- completed works
- high-risk/anomalous works
- state/constituency summaries

### Work Explorer
Filters:
- state
- constituency
- MP
- category
- status where available
- amount range
- risk level

### Work Details
Show only source-supported fields:
- work ID
- work name
- description
- MP
- constituency
- recommended amount
- expenditure
- dates
- agency/vendor
- risk score
- anomaly reasons
- source/provenance

### Anomaly Dashboard
Show:
- risk distribution
- top anomalies
- anomaly type
- explainable reasons
- drill-down

### Data Sources / Methodology
Explain:
- MPLADS source
- download dates
- processing method
- limitations
- unavailable fields

## UI principles
- professional public-accountability design
- clear charts and tables
- avoid sensational accusations
- use "risk indicator" / "requires review"
- make analytical claims traceable
