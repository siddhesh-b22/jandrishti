1. Client frontend/src/api/client.ts User triggers action in UI. Axios intercepts request, attaches Authorization: Bearer <JWT>, and dispatches JSON payload. FastAPI Gateway Signed HTTP Request
2. Auth backend/auth.py Decodes JWT using HMAC-SHA256. Resolves user identity, active statutory role, state, and parliamentary constituency. AuthenticatedUser Session Authenticated
3. Security backend/rbac_abac.py Dual Validation:
1. RBAC: Checks if role has permission on resource.
2. ABAC: Enforces territorial boundary and verifies no immutable fields (e.g. expenditure) are touched.		 State Machine / Service HTTP 403 if out of jurisdiction
4. Scope backend/scope.py Generates parameterized SQL WHERE fragments restricting rows to the official's mandate (e.g. state_normalized = ?). Database Query Strict Data Isolation
5. Logic backend/gov_service.py Executes statutory business logic (e.g., sanction order issuance, milestone tracking) and triggers tamper-proof audit logging. backend/db_engine.py Atomic DB Transaction
6. Persist backend/db_engine.py Attempts commit to Cloud PostgreSQL. If network fails, automatically falls back to local SQLite with zero downtime. PostgreSQL / SQLite Data Persisted & Logged

Forensic Engine Mathematical Formula What Actually Happens (Inspection Logic) Weight Action Taken
1. Semantic Duplication Jaccard(A, B) > 0.85
Levenshtein(Title) < 3		 Scans all past works in the same Gram Panchayat. If a project description matches an existing asset (e.g. "Community Hall Ward 4" funded twice), it flags potential double-invoicing. 35% Immediate Sanction Hold
2. Vendor Cartel (HHI) HHI = Σ (Market Share_i)²
Threshold: > 2500		 Calculates vendor revenue share within each parliamentary constituency. If 1 or 2 contractors win over 60% of all tenders, flags collusive bidding cartel. 25% Vigilance Inquiry
3. Benford's Law P(d) = log10(1 + 1/d)
Chi-Square p < 0.05		 Evaluates the natural logarithmic frequency of leading digits across all vouchers. Human-fabricated invoices cluster unnaturally around 4, 7, or 9, failing Benford tests. 20% Forensic Audit Flag
4. Expenditure Velocity Z = (Spend - μ) / σ
Z-Score > 3.0		 Compares spending rate in March (financial year-end) vs monthly average. Disproportionate spikes ("March Rush") indicate hasty fund dumping without physical milestones. 20% Audit Case Queued
5. Predictive Delay RandomForestRegressor()
Execution Velocity Ratio		 Machine learning model predicting expected completion date based on terrain, sector, and district track record. Detects stalled projects before public outcry. Auxiliary Milestone Warning

Step Layer & File Code Execution & Security Guarantee Failure / Error Handling
01 frontend/src/api/client.ts Axios request interceptor reads jandrishti_token. If token is missing, intercepts and redirects to /login. Auto-redirect to login
02 backend/auth.py verify_bearer_token decodes JWT. Rejects expired tokens or invalid signatures. Resolves role and territorial scope. HTTP 401 Unauthorized
03 backend/rbac_abac.py check_permission() evaluates whether user has permission. Enforces territorial boundary (e.g. Maharashtra MP cannot touch Bihar records). HTTP 403 Forbidden
(Cross-Jurisdiction Denied)
04 backend/workflow.py validate_workflow_transition() checks state graph. Prevents illegal skips (e.g. Draft directly to Sanctioned). HTTP 400 Bad Request
(Illegal State Transition)
05 backend/db_engine.py Executes parameterized SQL query via PostgresConnection. In case of network disconnection, falls back to SQLite transparently. HTTP 500 DB Error (Logged)
06 backend/audit_logger.py Records user ID, IP address, timestamp, previous state, and new state. Ensures complete auditability for parliamentary inquiries. Guaranteed audit persistence
🛡️ 5. Statutory Authority Matrix & Separation of Powers
Summary of rights and restrictions across the 6 statutory governance tiers.
Role & Rank Jurisdiction Scope Statutory Powers (What they CAN do) Strict Restrictions (What they CANNOT do)
RANK 1
MINISTRY_ADMIN		 Pan-India
(National Corpus)		 View all 36 States, configure system risk weights, approve central dockets, manage system users, global audit review. Cannot alter ground physical milestone records; cannot bypass district techno-scrutiny.
RANK 2
STATE_NODAL		 Designated State
(user.state)		 Review district dockets, grant statutory Financial Sanction (AS/FS), reject non-compliant works, monitor state budget quotas. Cannot access, approve, or modify records of any other Indian State.
RANK 3
DISTRICT_AUTHORITY		 Designated District
(user.district)		 Techno-economic scrutiny, tender floating, contractor assignment, milestone updates, geo-tagged photo uploads, release final payment. Cannot create work recommendations; cannot sanction outside district; cannot modify treasury transaction values directly.
RANK 4
MEMBER OF PARLIAMENT		 Parliamentary Seat
(user.mp_id)		 Draft and submit work recommendations within ₹5 Crore entitlement; track execution velocity; view constituency ledger. Locked from editing after submission; cannot approve works; cannot access other MPs' dockets.
RANK 5
STATUTORY AUDITOR		 National Mandate
(CAG / Independent)		 Inspect Benford flags, cartel HHI scores, duplicate work dockets; create forensic audit cases; flag transactions for recovery. Read-only to financial ledgers; cannot disburse, approve, or alter financial figures.
RANK 6
GENERAL CITIZEN		 Open Public
(National Read-Only)		 Inspect all works on interactive maps; search MP utilization; scan QR code plaques on physical assets; submit ground discrepancy feedback. Zero mutation power on official records; cannot edit or sanction works.

Open backend/workflow.py: edit RECOMMENDATION_TRANSITIONS dictionary and TRANSITION_AUTHORITY permission maps.

3. Adjust Forensic Risk Weights

Open backend/risk_engine.py: edit DEFAULT_WEIGHTS or call PUT /api/v1/risk-weights to change weights dynamically via REST API.
